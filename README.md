
# ISTE - KEC Student Chapter

The official website for the **ISTE (Indian Society for Technical Education) Student Chapter** at **Kongu Engineering College (KEC)**.

This platform showcases our events, team members, gallery, and contact information, serving as a hub for innovation and technical excellence.

## 🚀 Features

- **Dynamic Animations**: Engaging UI with smooth reveal animations.
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop devices.
- **Event Timeline**: A visual journey of our past and upcoming events.
- **Team Carousel**: Interactive slider to meet our office bearers.
- **Gallery**: A collection of memories from our activities.

## 🛠️ Technology Stack

- **Frontend**: React.js (Vite), CSS3, Bootstrap 5
- **Backend**: Node.js, Express.js
- **Icons**: Boxicons

## 📦 Installation & Setup

Follow these steps to run the project locally:

1.  **Clone the Repository**
    ```bash
    git clone https://github.com/bharathari1302/ISTE---KEC-STUDENTS-CHAPTER-React-.git
    cd "ISTE - KEC (website) - React"
    ```

2.  **Setup Backend**
    ```bash
    cd server
    npm install
    npm run dev
    ```
    The server will start on [http://localhost:5000](http://localhost:5000).

3.  **Setup Frontend**
    Open a new terminal configuration:
    ```bash
    cd client
    npm install
    npm run dev
    ```
    The application will run on [http://localhost:5173](http://localhost:5173).
